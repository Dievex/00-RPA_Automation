# 04 · Casos de Uso Detallados

En esta sección se profundiza en los 4 casos de uso críticos que forman el núcleo del sistema de automatización.

## Listado de Casos de Uso Nucleares

1. [**Registrar Declaración**](./registrar_declaracion.md) - Captura de datos inicial en la interfaz web.
2. [**Enviar a SAP**](./enviar_sap.md) - Disparo de la petición de automatización.
3. [**Procesar Declaración**](./procesar_declaracion.md) - Ejecución de la lógica del robot en SAP GUI.
4. [**Cambio de Contraseña Automático**](./cambio_contrasena_automatico.md) - Mantenimiento autónomo de credenciales.

## Resumen de Actores involucrados
- **Operario:** Inicia el proceso mediante el registro y envío.
- **Robot RPA:** Ejecuta la lógica de procesamiento y mantenimiento en SAP.
